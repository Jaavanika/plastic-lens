# On-device tests

`classifier_parity_test.dart` runs the bundled ONNX model on a real device or
emulator and checks it against Python's outputs (PLAN Section 4).

```powershell
adb shell cmd connectivity airplane-mode enable   # prove it works offline
flutter test integration_test/classifier_parity_test.dart -d <device-id>
adb shell cmd connectivity airplane-mode disable
```

`fixtures.g.dart` is generated by `ai_model/export/verify_onnx.py`, together with
`test/fixtures/`. Re-run that script after retraining.
